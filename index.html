  • DeepStruggle

    Mikhail Dektiarev's project. I contribute.

    A bot that plays the board game Twilight Struggle. It has a C++ rules engine, networks trained by self-play, and search at play time. The whole thing runs in a browser tab, so you can sit down and lose to it.

    My work is on search and evaluation: a rollout-based search that outplayed the earlier one, experiments on whether what search finds can be trained back into the network, and a census of blunders the engine can prove are mistakes.

  • struggler

    My fork of Alejandro Pinel Martínez's engine.

    A Python engine for the same game, built so that bots can be swapped in and played against each other. One of them is an LLM player that reads the rules and a strategy guide, drafts a plan each turn, and decides when to abandon it.

    In my fork I rebuilt the non-LLM strategic bot: country values fitted from games, an opening book, tree-search experiments, and a win-probability model checked on held-out games. A change only ships if it wins a tournament run in CI.

  • MTGA Draft Tool

    Tom Szymanski's project. I contribute.

    A draft assistant for Magic: The Gathering Arena that rates each pick using 17Lands data.

    I work on the draft advisor: a deck score built from named features, a harness that replays past drafts through it, and tests of competing pick rules against real game results.
